# ربات NDS — اسکنر و سیگنال‌دهی بر اساس Nodal Displacement Sequencing

ربات پایتونی که بازار فیوچرز بایننس را از دید استراتژی **NDS** رصد می‌کند و سیگنال‌های **LONG / SHORT تأییدشده** را با مدیریت سرمایه در **تلگرام** (فارسی) می‌فرستد. اندیکاتور TradingView همان منطق هم در پوشه `tradingview/` است.

> ⚠️ این ابزار تحلیلی است و سودی را تضمین نمی‌کند. ربات هیچ سفارشی در صرافی ثبت نمی‌کند و به حساب صرافی وصل نیست.

## امکانات
- **موتور NDS**: سکانس نودها (1-2-3)، ۱-۲های باز، هوک (نوع A/B) و سطح ۸۶.۴٪، 123Flag، تقارن نودها
- **جهت از دو تایم‌فریم**: ۱۵ دقیقه و ۴ ساعته (قابل تغییر)
- **ناحیه خوش‌قیمت**: «صبر کن تا قیمت برسد» و ماشه ورود (123Flag یا نود ۳ داخل ناحیه)
- **کندل هیکن آشی** برای تشخیص ساختار؛ ورود، حدضرر و هدف با قیمت واقعی
- **اسکنر**: ۳۰ ارز پرحجم فیوچرز بایننس، رتبه‌بندی سیگنال‌ها (R/R و کارنامه هر ارز)، فیلتر نوسان
- **مدیریت سرمایه**: حجم بر اساس درصد ریسک، اهرم لازم، سقف پوزیشن باز، سقف ضرر روزانه، بستن نیمی از حجم در 1R و انتقال حدضرر به نقطه ورود
- **حساب آزمایشی (Paper)** و کارنامه در `signals.csv`
- **تطبیق با بازار**: انتخاب خودکار طول پیوت هر چند ساعت بر اساس بک‌تست کندل‌های اخیر
- فقط کتابخانه‌های استاندارد پایتون — نیازی به `pip install` نیست

## سیستم موردنیاز (خلاصه)
- **ویندوز:** Windows 10/11 + پایتون 3.10 یا جدیدتر + اینترنت دائمی
- **سرور مجازی (پیشنهادی):** Ubuntu 24.04، ۱ هسته، ۱ گیگ رم، ۱۰ گیگ دیسک، **IPv4**، محل **اروپا**
- حساب تلگرام و یک ربات از BotFather

📘 **راهنمای کامل نصب قدم‌به‌قدم: [docs/INSTALL.md](docs/INSTALL.md)**

## راه‌اندازی سریع

### ویندوز
1. پایتون 3.10 یا جدیدتر نصب باشد.
2. `config.example.txt` را به `config.txt` کپی کنید و `TELEGRAM_TOKEN` را وارد کنید.
3. در تلگرام به ربات خودتان `/start` بفرستید.
4. `test.bat` → پیام آزمایشی؛ سپس `start.bat`.

### سرور لینوکس (Ubuntu 22.04 / 24.04، در اروپا)
```bash
scp deploy/install_nds_vps.sh root@SERVER_IP:/root/
ssh root@SERVER_IP
bash install_nds_vps.sh
```
اسکریپت توکن و CHAT_ID را می‌پرسد و ربات را به‌صورت سرویس اجرا می‌کند.
مدیریت: `systemctl status nds-bot` · `journalctl -u nds-bot -f` · `systemctl restart nds-bot`

> بایننس IPهای برخی کشورها (مثلاً آمریکا) را مسدود می‌کند؛ سرور را در اروپا بگیرید.

## دستورهای تلگرام
| دستور | کار |
|---|---|
| `/scan` | ارزهای مستعد لانگ و شورت |
| `/balance` | موجودی حساب آزمایشی و پوزیشن‌های باز |
| `/report` | کارنامه سیگنال‌ها |
| `/status` | وضعیت ارزهای ثابت (`SYMBOLS`) |

## پیام‌ها
- `📢 الان پوزیشن LONG/SHORT باز کن` — ورود، حدضرر، هدف ۱ و نهایی، حجم، اهرم، ریسک
- `💵` هدف ۱ — `🏁` هدف نهایی — `🛑` حدضرر — `⚖️` سر به سر

## اجرای خط فرمان
```bash
python nds_bot.py            # اجرای دائمی
python nds_bot.py --test     # پیام آزمایشی و وضعیت فعلی
python nds_bot.py --backtest # بک‌تست روی ۱۰۰۰ کندل اخیر
```
