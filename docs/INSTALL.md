# راهنمای نصب ربات NDS

این راهنما همه چیزِ لازم برای راه‌اندازی ربات را از صفر توضیح می‌دهد: سیستم موردنیاز، ساخت ربات تلگرام، نصب روی ویندوز، نصب روی سرور مجازی (اجرای ۲۴ ساعته)، نصب اندیکاتور TradingView، به‌روزرسانی و رفع اشکال.

---

## ۱) سیستم موردنیاز

### اجرا روی کامپیوتر شخصی (ویندوز)
| مورد | حداقل |
|---|---|
| سیستم‌عامل | Windows 10 یا 11 (۶۴ بیتی) |
| پایتون | 3.10 یا جدیدتر (از Microsoft Store یا python.org) |
| رم / پردازنده | هر کامپیوتر معمولی؛ ربات حدود ۱۰۰ مگابایت رم مصرف می‌کند |
| اینترنت | اتصال دائمی؛ دسترسی به `fapi.binance.com` و `api.telegram.org` |
| شرط | کامپیوتر باید روشن بماند و به خواب (Sleep) نرود |

### اجرا روی سرور مجازی (پیشنهادی — ۲۴ ساعته)
| مورد | حداقل / پیشنهاد |
|---|---|
| سیستم‌عامل | **Ubuntu 24.04 LTS** یا 22.04 LTS (Debian 12 هم کار می‌کند) |
| پردازنده | ۱ هسته |
| رم | ۱ گیگابایت |
| دیسک | ۱۰ تا ۲۰ گیگابایت |
| آدرس IP | **IPv4 عمومی الزامی است** (پلن‌های فقط IPv6 کار نمی‌کنند) |
| محل سرور | **اروپا** (فرانکفورت، آمستردام، پاریس، نورنبرگ). بایننس IPهای آمریکا و برخی کشورها را مسدود می‌کند |
| ترافیک | چند گیگابایت در ماه کافی است |

نمونه سرویس‌دهنده‌ها (قیمت‌ها تقریبی است؛ قبل از خرید در سایت خودشان چک کنید):
- **Netcup** (آلمان) — VPS pico / nano، ارزان‌ترین، قرارداد ۶ تا ۱۲ ماهه
- **DigitalOcean**، **Akamai Linode**، **Vultr** — ماهانه حدود ۵ تا ۶ دلار، بدون قرارداد
- **Scaleway** (فرانسه)، **Hetzner** (آلمان)

### موارد مشترک
- یک حساب **تلگرام**
- یک **ربات تلگرام** (توکن از BotFather — بخش ۲)
- برای اندیکاتور: یک حساب **TradingView** (رایگان هم کافی است)

---

## ۲) ساخت ربات تلگرام (یک بار)
1. در تلگرام `@BotFather` را پیدا کنید (تیک آبی دارد) و **Start** بزنید.
2. بفرستید: `/newbot`
3. یک نام نمایشی بدهید، مثلاً `NDS Signals`.
4. یک یوزرنیم که به `bot` ختم شود، مثلاً `myname_nds_bot`.
5. BotFather یک **توکن** شبیه `123456789:AAH...` می‌دهد. آن را جایی امن نگه دارید و **برای هیچ‌کس نفرستید**.
6. روی لینک ربات جدیدتان بزنید و **Start** را بزنید (بدون این مرحله ربات نمی‌تواند به شما پیام بدهد).

---

## ۳) نصب روی ویندوز
1. **پایتون را نصب کنید:** Microsoft Store را باز کنید، `Python 3.13` را جستجو و نصب کنید.
   (یا از python.org؛ در نصب‌کننده تیک **Add python.exe to PATH** را بزنید.)
2. **کد را بگیرید:** در صفحه همین ریپازیتوری روی **Code → Download ZIP** بزنید و فایل را در یک پوشه (مثلاً روی Desktop) باز کنید.
3. **تنظیمات:** فایل `config.example.txt` را کپی کنید و اسم کپی را `config.txt` بگذارید.
   آن را با Notepad باز کنید و در خط `TELEGRAM_TOKEN=` توکن BotFather را جایگزین `PASTE_YOUR_TOKEN_HERE` کنید. ذخیره کنید.
4. **تست:** روی `test.bat` دوبار کلیک کنید. باید در تلگرام «پیام آزمایشی» برسد.
   ربات در اولین اجرا شناسه چت شما (`CHAT_ID`) را خودش پیدا و ذخیره می‌کند.
5. **روشن کردن:** روی `start.bat` دوبار کلیک کنید. تا وقتی این پنجره باز است ربات کار می‌کند؛ برای خاموش کردن پنجره را ببندید.
6. **جلوگیری از خواب ویندوز:** Settings → System → Power → Sleep = **Never** (وقتی به برق وصل است).

## ۴) نصب روی سرور مجازی لینوکس (۲۴ ساعته)
اسکریپت `deploy/install_nds_vps.sh` کل ربات را داخل خودش دارد. پایتون را نصب می‌کند، توکن را می‌پرسد و ربات را به‌صورت سرویس `systemd` اجرا می‌کند (با ری‌استارت خودکار بعد از خطا یا ریبوت سرور).

1. **سرور بخرید:** Ubuntu 24.04، محل اروپا، کوچک‌ترین پلن، **IPv4 فعال**. از پنل سرویس‌دهنده IP و رمز `root` را بردارید.
2. **فایل را به سرور بفرستید** (در PowerShell ویندوز، `IP` را با IP سرور عوض کنید):
   ```powershell
   scp "C:\مسیر\nds-bot\deploy\install_nds_vps.sh" root@IP:/root/
   ```
3. **وصل شوید و نصب کنید:**
   ```bash
   ssh root@IP
   bash install_nds_vps.sh
   ```
   - توکن تلگرام را می‌پرسد (هنگام تایپ دیده نمی‌شود).
   - `CHAT_ID` را می‌پرسد: از خط `CHAT_ID=` در `config.txt` کامپیوترتان کپی کنید، یا خالی بگذارید تا خودش پیدا کند.
4. اسکریپت دسترسی سرور به بایننس و تلگرام را چک می‌کند. اگر بایننس در دسترس نبود، سرور را در کشور دیگری (اروپا) بگیرید.
5. در پایان پیام «🤖 ربات NDS روشن شد» در تلگرام می‌آید.
6. **ربات روی کامپیوتر را خاموش کنید**؛ وگرنه هر پیام دو بار می‌آید.

### دستورهای مدیریت روی سرور
```bash
systemctl status nds-bot        # روشن است یا نه
journalctl -u nds-bot -f        # گزارش زنده (خروج: Ctrl+C)
systemctl restart nds-bot       # ری‌استارت
systemctl stop nds-bot          # خاموش
nano /opt/nds-bot/config.txt    # تغییر تنظیمات، بعد restart
```

### به‌روزرسانی روی سرور
نسخه جدید `install_nds_vps.sh` را به سرور بفرستید و دوباره `bash install_nds_vps.sh` را اجرا کنید. تنظیمات، توکن و کارنامه حفظ می‌شوند.

## ۵) نصب اندیکاتور TradingView
1. در TradingView پایین صفحه **Pine Editor** را باز کنید.
2. کد پیش‌فرض را کامل پاک کنید (Ctrl+A و Delete).
3. محتوای `tradingview/NDS_Pro.pine` را کامل کپی و paste کنید.
4. **Save** بزنید (اسم: `NDS Pro`) و بعد **Add to chart**.
5. از این به بعد: **Indicators → My scripts → NDS Pro**.
6. برای خواندن ساختار از هیکن آشی: نوع کندل چارت را روی **Heikin Ashi** بگذارید (اعداد دقیق ورود/حدضرر را از پیام ربات بردارید، چون قیمت‌های چارت هیکن آشی قیمت واقعی نیستند).

تنظیمات پیشنهادی: چارت ورود ۵ دقیقه، جهت ۱۵ دقیقه و ۴ ساعته، طول پیوت ۵ (روی چارت ۱۵ دقیقه: ۸).

برای بک‌تست، `tradingview/NDS_Strategy_backtest.pine` را به همین روش اضافه کنید و نتیجه را در **Strategy Tester** ببینید.

## ۶) تنظیمات مهم `config.txt`
| کلید | پیش‌فرض | توضیح |
|---|---|---|
| `TELEGRAM_TOKEN` | — | توکن BotFather |
| `CHAT_ID` | خودکار | شناسه چت شما |
| `SCAN` / `SCAN_TOP` | `yes` / `30` | رصد ارزهای پرحجم |
| `MARKET` | `futures` | `futures` (لانگ و شورت) یا `spot` |
| `ENTRY_TF` | `5m` | تایم‌فریم ورود |
| `DIR_TF_A` / `DIR_TF_B` | `15m` / `4h` | تایم‌فریم‌های جهت |
| `CANDLES` | `heikin_ashi` | `heikin_ashi` یا `normal` |
| `MODE` | `paper` | `paper` = حساب آزمایشی، `signal` = فقط سیگنال |
| `ACCOUNT_BALANCE` | `1000` | سرمایه برای محاسبه حجم (دلار) |
| `RISK_PERCENT` | `1` | ریسک هر معامله (درصد) |
| `MAX_LEVERAGE` | `5` | سقف اهرم |
| `MAX_OPEN_POSITIONS` | `2` | حداکثر پوزیشن هم‌زمان |
| `DAILY_MAX_LOSS_PERCENT` | `3` | توقف ورود جدید بعد از این مقدار ضرر روزانه |
| `PARTIAL_TP` | `yes` | بستن نیمی از حجم در 1R و حدضرر به نقطه ورود |
| `REPORT_EVERY_HOURS` | `0` | گزارش دوره‌ای (۰ = خاموش) |

بعد از هر تغییر، ربات را ری‌استارت کنید.

## ۷) رفع اشکال
| مشکل | راه‌حل |
|---|---|
| حروف فارسی در پنجره سیاه ویندوز برعکس است | فقط مشکل نمایش کنسول ویندوز است؛ پیام‌های تلگرام درست‌اند |
| پیامی در تلگرام نمی‌آید | توکن را چک کنید؛ در تلگرام به ربات `/start` بفرستید؛ `CHAT_ID` را خالی کنید و دوباره اجرا کنید |
| `python` شناخته نمی‌شود | پایتون را از Microsoft Store نصب کنید یا در نصب python.org تیک PATH را بزنید |
| خطای دریافت داده / HTTP 451 یا 403 از بایننس | IP شما (یا سرور) توسط بایننس مسدود است؛ سرور را در اروپا بگیرید |
| هر پیام دو بار می‌آید | ربات هم‌زمان روی کامپیوتر و سرور روشن است؛ یکی را خاموش کنید |
| «تاریخچه کافی نیست» برای یک ارز | ارز تازه لیست شده؛ ربات خودش از آن رد می‌شود |

گزارش کار ربات در `nds_bot.log` (ویندوز) یا `journalctl -u nds-bot` (سرور) است.

---

## ۸) امنیت
- `config.txt` (حاوی توکن)، `state.json`، `signals.csv` و لاگ در `.gitignore` هستند و هرگز در گیت‌هاب آپلود نمی‌شوند.
- توکن را در هیچ issue، commit یا پیامی منتشر نکنید. اگر لو رفت، در BotFather با `/revoke` توکن جدید بگیرید.
- ربات هیچ سفارشی در صرافی ثبت نمی‌کند و به کلید API صرافی نیاز ندارد.
